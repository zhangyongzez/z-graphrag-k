# 管理页面使用指南

访问 `http://localhost:8000/` 打开管理页面。首次启动会自动创建管理员账号，
密码见启动日志（或用 `ADMIN_PASSWORD` 环境变量指定）。

---

## 〇、登录与权限

### 登录

- **本地账号**：用户名 + 密码
- **AD 域账号**：管理员在「配置 → AD 域认证」启用后，直接用域账号登录

### 两种角色

| 角色 | 说明 |
|---|---|
| **管理员** | 由环境变量 `ADMIN_USERNAME` / `ADMIN_PASSWORD` 决定，**唯一**。<br>可访问配置、模型管理、系统看板、用户管理，可查看所有知识库 |
| **普通用户** | 只能使用自己的知识库，以及管理员分配给 TA 的知识库或公共知识库 |

普通用户看到的侧边栏没有「管理员」分组；即使直接调用接口，
服务端也会返回 403。

---

## 一、看板

首页，展示**当前用户可见**的知识库概览。

### 统计卡片

| 卡片 | 含义 |
|---|---|
| **知识库** | 可见的知识库总数 |
| **文档** | 去重后的文档总数 |
| **向量块** | 向量总条数 |
| **Embedding** | 当前 embedding 提供方与维度 |
| **向量库** | `lite` 或 `milvus` |
| **LLM** | 当前模型提供方与模型名 |

> 统计是实时计算的：每次打开看板都会遍历 collection 统计行数。
> 百万级数据量时建议改为定时缓存。

---

## 二、知识库

### 2.1 列表页

展示当前用户可见的知识库：名称、描述、归属、文档数、向量块数、创建时间。

### 2.2 新建知识库

点击右上角「**+ 新建知识库**」：

- **名称**：必填，不可重名
- **描述**：选填

创建者自动成为拥有者，可删除该库。

### 2.3 详情页

#### 上传文档

支持两种方式：

1. **点击**虚线区域，从文件选择器选文件（可多选）
2. **拖拽**文件到虚线区域

支持格式：

| 类别 | 扩展名 |
|---|---|
| 文本 | `txt` / `md` / `markdown` |
| 文档 | `pdf` / `doc` / `docx` |
| 演示 | `pptx` |
| 表格 | `xlsx` / `xls` / `csv` |
| 网页 / 标记 | `html` / `htm` / `xml` / `json` |

上传后每行会显示结果：

```
产品手册.md      ✓ 3 块
部署指南.txt     ✗ 不支持的类型: .xyz
```

> **重复上传是安全的**：系统用「知识库 + 文件标识 + 块序号」生成稳定主键，
> 同一文件再次上传会**覆盖**而不是追加，不会产生重复数据。

#### 文档列表

展示该知识库下的所有文档及其向量块数。
点击「删除」可移除单个文档的所有向量块（有二次确认）。

> 只有拥有者或拥有写权限的用户才能上传/删除文档。

### 2.4 删除知识库

详情页右上角「删除知识库」，会**同时删除 Milvus collection 和注册记录**，
不可恢复，需二次确认。只有**拥有者**或**管理员**可以删除。

## 三、对话

### 3.1 会话

左侧是会话列表，点击「**+ 新建对话**」创建新会话。

- 每个会话独立保存：消息历史、知识库权重、选择的模型
- 会话仅创建者可见
- 点击会话右侧「×」删除

### 3.2 配置知识库权重（需求 2.2）

会话上方的「知识库权重」区域：

- 勾选要使用的知识库（可多选）
- 拖动滑块设置权重（0 ~ 2，默认 1.0）
- 权重会持久化到该会话

多库检索时，每个库先按 `top_k` 取候选，再用 min-max 归一化后的分数
乘以权重重排，取最终前 `top_k`。

### 3.3 选择大模型（需求 2.2）

「大模型」下拉框：

- **跟随全局**：使用管理员在配置页设置的模型
- **指定模型**：仅本会话生效

### 3.4 提问

在底部输入框输入问题：

- **Enter** 发送
- **Shift + Enter** 换行

回答是**流式输出**的，逐字显示。生成完成后，回答下方会出现
「引用 N 条资料」，展开可查看命中的原文片段和来源文件。

### 3.5 流式协议

前端使用 SSE 接收，事件顺序：

```
event: sources
data: {"sources": [{"filename": "产品手册.md", "preview": "..."}]}

event: delta
data: {"text": "根据"}

event: delta
data: {"text": "资料"}

event: done
data: {}
```

## 四、系统配置（管理员）

「系统配置」页面**只做选择与参数调整，不维护模型**。
模型本身在「模型管理」页新增，新增后这里立刻出现下拉选项。

| 分组 | 内容 | 生效方式 |
|---|---|---|
| **Embedding 模型** | 下拉选择模型；设备（CPU/GPU）、批大小、最大长度、归一化 | 需重启 |
| **大模型** | 下拉选择模型；温度、最大 Tokens、超时 | 即时生效 |
| **切分与检索** | Top-K、相似度阈值、切块大小/重叠 | 即时生效 |
| **向量库** | Milvus Lite / 服务端、地址、Token | 需重启 |
| **AD 域认证** | LDAP 地址、Base DN、服务账号、用户过滤器 | 即时生效 |

- 每个字段下方都有**说明文字**，解释该参数的含义和调整建议
- 与默认值不同的字段会标记「**已修改**」
- 标有 **↻** 的 Tab 表示修改后需要重启服务
- 右上角「**恢复默认**」可一键清空所有自定义配置
- 密钥类字段返回时脱敏；留空表示不修改
- 没有可选模型时会提示跳转到「模型管理」

## 五、模型管理（管理员）

模型管理维护**所有**模型（大模型 + Embedding），每个模型自带连接信息。

### 5.1 新增模型

点击「**+ 新增模型**」，按类型填写：

| 类型 | 提供方 | 需要填写 |
|---|---|---|
| **大模型** | Anthropic | API 地址、API Key、模型标识 |
| | OpenAI 兼容 | API 地址（含 `/v1`）、API Key、模型标识 |
| | Ollama | API 地址、模型标识 |
| | Mock | 无（仅测试） |
| **Embedding** | 本地目录 | 模型目录路径、维度（自动探测） |
| | OpenAI 兼容 | API 地址、API Key、模型标识、维度 |
| | Ollama | API 地址、模型标识、维度 |
| | 哈希占位 | 无（仅测试） |

本地模型目录需符合 sentence-transformers 约定：

```
models/bge-m3/
├── config.json            ← 必需
├── model.safetensors      ← 必需（或 pytorch_model.bin）
├── tokenizer.json
└── ...
```

填写路径后失焦会自动探测，从 `config.json` 读取维度并提示是否有效。

> **密钥只存在模型记录里**，接口永远不返回明文，列表只显示「已配置」。

### 5.2 管理已有模型

- 顶部 Tab 按「全部 / 大模型 / Embedding」筛选
- 点击「编辑」修改连接信息（密钥留空表示不修改）
- 点击「删除」移除模型；已被配置页选中的模型删除后，配置回退到 .env

### 5.3 上传模型文件

接口：`POST /api/admin/models/upload?subdir=bge-m3`，可分批上传。

## 六、系统看板（管理员）

- **总量**：知识库 / 文档 / 向量块
- **服务状态**：API 服务、向量库、大模型、Ollama 的地址与健康状态
- **模型配置**：Embedding / 大模型 / 向量库的完整配置与路径
- **全部知识库**：所有知识库（不受权限限制）的集合名、维度、文档数

---

## 七、用户管理（管理员）

- 查看所有用户：用户名、显示名、角色、来源（local / ad）、状态、最近登录
- 新建用户（普通用户 / 管理员）
- 停用 / 启用 / 删除普通用户
- 查看最近 30 条操作审计

> 管理员账号由环境变量决定，不能在页面上删除或降级。
> 知识库授权通过 `POST /api/kb/{id}/permissions` 接口分配。

## 八、接口速查

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/auth/login` | 登录 |
| GET | `/api/auth/me` | 当前用户 |
| GET/POST | `/api/auth/users` | 用户列表 / 新建（管理员） |
| GET | `/api/kb` | 可见知识库列表 |
| POST | `/api/kb` | 新建知识库 |
| GET | `/api/kb/{id}/documents` | 文档列表 |
| POST | `/api/kb/{id}/upload` | 上传文件 |
| POST | `/api/kb/{id}/permissions` | 授权（管理员） |
| PUT | `/api/kb/{id}/public` | 设为公共（管理员） |
| GET/POST | `/api/chat/conversations` | 会话列表 / 新建 |
| PATCH | `/api/chat/conversations/{id}` | 改标题 / 权重 / 模型 |
| POST | `/api/chat/stream` | 流式问答 |
| GET/PUT | `/api/admin/config` | 读取 / 保存配置 |
| GET/POST | `/api/admin/models` | 模型列表 / 登记 |
| GET | `/api/admin/dashboard` | 系统看板 |
| GET | `/api/admin/audit` | 审计日志 |

完整接口文档：<http://localhost:8000/docs>
